# FAQ — Hello Agentic

## What is this?
A minimal product to exercise the AI-Engineering plugin: human pipelines + KB → AIUxer interaction → AIEngineer tech deltas.

## Which GenUI band?
**Controlled + Declarative (closed catalog).** Not open-ended HTML.

## What can the assistant show?
Only catalog types: `greeting`, `faq-card`, `tip-chip`. Unknown types are dropped.

## Where is my “memory”?
Session notes in the UI memory panel (client-only in v1). Not a durable server store — see Book `02-STACK`.
